# Game cursors

These original SVG cursors use a 40 × 40 pixel grid, stepped outlines, and a gold palette. The user-provided Cambria screen photographs informed the interaction states. No pixels were copied from those photographs.

| File | State | Hotspot |
| --- | --- | --- |
| `arrow.svg` | Clear terrain and default game surface | 4, 3 |
| `pointer.svg` | Buttons and interactive structures | 6, 3 |
| `grab.svg` | Clansmen and camera pan readiness | 19, 20 |
| `grabbing.svg` | Camera dragging | 19, 20 |
| `blocked.svg` | Impassable terrain | 20, 20 |

- CSS cursors retain native fallbacks.
- The browser draws the cursor independently of the game canvas.
- [The contact sheet](../../../../../../artifacts/qa/game-cursors.png) shows all five states.
