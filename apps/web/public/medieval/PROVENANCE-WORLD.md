## Render the sprites

- `atlas.json` records measured `source` and `trim` rectangles for all 24 transparent sprites. Use those rectangles when calling `drawImage`.
- `trim` has the form `[x, y, width, height]` in source pixels. It excludes transparent outer space using an alpha threshold of 32.
- `source` records the full assigned cell. `anchor` is the sprite bottom-center relative to that cell. Root positions and widths still need to be matched to game footprints.
- The generated sheets preserve the requested four-column order, but their row heights differ. Uniform `height / 3` clipping would cut tree roots or a chapel detail. The recorded rectangles preserve the full sprites.
- The buildings contain RGB color beneath fully transparent pixels. Render the PNG alpha channel; do not interpret raw RGB as a background plate.
- Ground textures use 313.5-pixel square cells. Sample a centered 300-pixel square inside each cell if texture borders become visible.

### In plain words

The PNG is a sheet of separate pieces. The rectangle list tells the renderer where to take each piece, so no tree roots or roof details get cut off.
